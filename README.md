# CohortLive promotional site

*Learn live. Test real.* Live at **https://cohortlive.netlify.app**. It's a single-page Vite + React + TypeScript + Tailwind site (originally generated with Bolt) for CohortLive's live classes and proctored GATE mocks.

[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-w1ynxzqb)

## Setup

```powershell
npm install
copy .env.example .env
npm run dev          # local preview
npm run build        # production build into dist/
npm run lint; npm run typecheck
```

| Variable | Default | Used by |
|---|---|---|
| `VITE_APP_URL` | `https://cohortlive-portal.netlify.app` | **Take a Mock Test** (`/student`), **Login**, **Register**, **Trainer Login** (`/trainer`) |
| `VITE_APK_URL` | `https://github.com/AsmitaV9/cohort-live-student-app/releases/latest` | **Download App** |

The variables are also set in Netlify (Site configuration → Environment variables). If they're missing, the fallbacks in `src/config/links.ts` keep the buttons working.

## Deploy
Netlify builds and deploys every push to `main` of this repository.

## Content and brand
- Texts and links: `src/data/content.ts` and `src/config/links.ts`.
- Logo: `src/components/Logo.tsx`. Its colours follow light/dark mode through the `--logo-*` variables in `src/index.css`.
- The favicons, `og-image.png` and `/brand` are generated by `npm run brand` in `cohort-live-trainer-web`.
